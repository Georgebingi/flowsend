# FlowSend Frontend

A modern remittance and personal finance web application built with
Next.js.

## Overview

FlowSend is a fintech frontend platform that enables users to send money
internationally while managing their financial activities in a single,
intuitive interface. The application combines cross‑border transfers
with tools for budgeting, savings, bill management, insurance tracking,
and family financial coordination. Designed with scalability and
usability in mind, FlowSend serves as both a production‑ready UI
foundation and a high‑quality portfolio project.

## Key Features

-   **Dashboard:** Unified overview of balances, transactions, and
    financial activity\
-   **Send Money:** International transfer interface with transaction
    preview\
-   **Smart Allocation:** Automatically distribute funds into savings,
    bills, or other categories\
-   **Savings Goals:** Create and monitor goal‑based savings plans\
-   **Bill Management:** Track upcoming bills and schedule payments\
-   **Micro‑Insurance:** View policies and manage premium payments\
-   **Family Wallets:** Manage shared finances with role‑based access
    and limits

## Technology Stack

-   Next.js 14 (App Router)
-   React with TypeScript
-   Tailwind CSS
-   Lucide React Icons

## Getting Started

### Prerequisites

-   Node.js 18 or higher
-   npm or yarn

### Installation

Install project dependencies:

``` bash
npm install
```

### Development

Start the local development server:

``` bash
npm run dev
```

Open http://localhost:3000 in your browser.

### Production Build

Build and run the application for production:

``` bash
npm run build
npm start
```
